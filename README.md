## What is AgentX?

AgentX is a Flutter-based mobile platform for creating and using AI agents on Android and iOS. Users can describe an agent's purpose in natural language, tailor it to a particular task, and provide the tools required to carry out connected actions.

It is intended for LLM-powered automation involving structured tasks, chained tools, and autonomous execution. AgentX also provides a flexible mobile environment for exploring AI agents, multi-step workflow sequences, and MCP-oriented tool connections.

- Build specialized AI agents for individual tasks

- Combine connected tools into sequential workflow chains
- Execute multi-step operations autonomously
- Run agent actions through LLM-driven interactions
- Target both Android and iOS deployments

## Using AgentX

1. Open AgentX on the target device.
2. Add an agent that matches the job you want to automate.
3. Explain the intended behavior using a natural-language prompt.
4. Provide the tools required by the workflow.
5. Start the agent and allow it to coordinate the linked steps autonomously.
6. Inspect the output, then revise the prompt or tool chain when necessary.

A typical workflow looks like this:

- Create an agent for a clearly defined task
- Assemble the required tools in sequence
- Let the LLM manage the individual actions
- Modify the chain as the task requirements evolve
